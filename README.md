# Shaadan Akthar — AI/ML Developer Portfolio

A cutting-edge, interactive **3D Developer Portfolio** built for **Shaadan Akthar**, an Artificial Intelligence engineering student at AJ Institute of Engineering and Technology, Mangaluru.

Powered by **Three.js**, **React Three Fiber (R3F)**, **Drei**, **GSAP scroll animations**, and **Tailwind CSS**, featuring interactive 3D scene models, floating technology logos, and strict resume-verified factual accuracy.

---

## 🚀 Key 3D Features & Architecture

- **Interactive 3D Room Experience**: Fully rendered, responsive 3D developer studio room with dynamic lighting, camera controls, and ambient particles in the Hero section.
- **Interactive 3D Floating Tech Logos**: Real 3D interactive models for:
  - 🐍 **Python** (`/models/python-transformed.glb`)
  - ⚛️ **React** (`/models/react_logo-transformed.glb`)
  - 🟢 **Node.js** (`/models/node-transformed.glb`)
  - 🌐 **Three.js** (`/models/three.js-transformed.glb`)
  - 🐙 **Git** (`/models/git-svg-transformed.glb`)
- **Interactive 3D Terminal & Computer**: Realtime 3D computer model in the Contact section with dynamic camera orbits.
- **GSAP Scroll Animations**: Smooth timeline animations and reveal sequences for projects and experience.
- **Showcase Section**: Shaadan's 4 verified projects:
  - **GadgetHub** (Full-Stack React + Node + Express + MongoDB)
  - **AI Attendance System** (Computer Vision + OpenCV + InsightFace + Flask)
  - **Code Mentor AI** (Generative AI + Streamlit + Gemini API)
  - **Student Performance Prediction** (Machine Learning + Scikit-Learn)
- **Academic Foundation Timeline**: AJIET Mangaluru B.E. Artificial Intelligence (Started September 2024, 3rd Year).
- **Core Specializations Bento Grid**: Applied AI, Machine Learning, Computer Vision, Generative AI, Full-Stack Applications, Practical Problem Solving.
- **Contact & Direct Delivery**: Seamless form submission with direct email copy and fallback to `shaadanakthar@gmail.com`.

## 🛠️ Quick Start & Local Development

```bash
# Navigate to the project directory
cd "C:\Users\PC - 09\.gemini\antigravity\scratch\shaadan-portfolio"

# Start the Vite 3D development server
npm run dev
```

Open `http://localhost:5173/` in your browser.

### Production Build
```bash
npm run build
```
The optimized bundle will be compiled into `dist/`.
